# AI Payment Recovery Assistant

AI Payment Recovery Assistant helps businesses track overdue invoices and recover pending payments.

## Features
* Add and track invoices
* Calculate overdue days
* Give invoices Low, Medium, or High priority
* Generate payment reminder messages
* Simple recovery dashboard

## Tech Stack

* HTML, CSS, JavaScript
* Python, FastAPI
* Uvicorn, Pydantic

## How to Run
```bash
pip install -r backend/requirements.txt
uvicorn backend.main:app --reload
```

Then open `frontend/index.html` in your browser.
